# ParaDigMa Studio

## Overview

A Windows workspace for gait, tremor and pulse-rate analysis of sensor recordings.
Scientific processing and trained classifiers are provided by the **ParaDigMa**
toolbox, developed by its authors and contributors.

[Studio source](https://github.com/biomarkersParkinson/ParaDigMa-Studio) ·
[ParaDigMa documentation](https://biomarkersparkinson.github.io/paradigma/) ·
[ParaDigMa source](https://github.com/biomarkersParkinson/paradigma)

Development, testing and documentation were supported by OpenAI Codex.
