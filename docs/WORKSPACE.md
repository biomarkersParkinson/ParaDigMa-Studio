# Workspace guide

ParaDigMa Studio separates analysis configuration from result exploration in
four sidebar pages. The sidebar expands on hover; About is available at its
bottom or with F1.

| Page | Use |
| --- | --- |
| **Data** | Open recordings for one subject. Overview shows sensor and time statistics; Graphs overlays selected channels by modality; Tables shows original samples. |
| **Analyze** | Select any combination of gait, tremor and pulse rate, then configure shared parameters. One **i** explanation opens below the settings at a time. Run and Stop Analysis remain in the status row. |
| **Results** | Overview presents aggregates and recording coverage. Graphs compares selected module outputs in Detailed or 30-minute views; Tables preserves the original outputs. Save results and Export are available across tabs. Sensor context opens the source samples around a selected result. |
| **Runs** | Review status, parameters, warnings, errors, logs and output locations. Reopen saved results, reuse settings or delete selected runs after confirmation. Ctrl/Shift supports multiple selection; Clear all removes the history and associated unprotected outputs. |

Use the [user guide](USER_GUIDE.md) for settings, graph interpretation, sensor
context, saving and troubleshooting, and the [README](../README.md) for download
instructions and supported formats.
